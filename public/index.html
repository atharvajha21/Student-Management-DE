📌 System Relational Architecture

This project uses a normalized PostgreSQL 17 relational database running through Prisma ORM and an Express.js CommonJS backend.

  • Relational 3NF Schema: Zero redundancy across students, courses, enrollments, and attendance.
  • Foreign Key Cascades: Automatic referential cleanup prevents orphan records.
  • CHECK Constraints: Course credits strictly 1-6; Attendance status strictly Present / Absent.
  • Unique Integrity: Prevents duplicate student emails, course codes, and duplicate daily student attendance.
